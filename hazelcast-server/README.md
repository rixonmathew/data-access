# Hazelcast In-Memory Data Grid Module (`hazelcast-server`)

## Overview
The `hazelcast-server` module demonstrates clustering and distributed in-memory data grid (IMDG) configuration using Hazelcast.

---

## Technical Capabilities Tested & Validated

* Distributed in-memory data structures (IMap, IQueue).
* Clustered network join configurations and partition management.

---

## How to Run the Module

```bash
mvn test -pl hazelcast-server
```
