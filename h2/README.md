# H2 In-Memory Relational Module (`h2`)

## Overview
The `h2` module explores traditional blocking JPA/Hibernate data access on the in-memory H2 database.

---

## Technical Capabilities Tested & Validated

* Standard Spring Data JPA repositories.
* Entity lifecycle, generation strategies, and repository contract queries.

---

## How to Run the Tests

```bash
mvn test -pl h2
```
