# SQLite3 Embedded Database Module (`sqlite3`)

## Overview
The `sqlite3` module explores embedded, serverless, transactional SQL storage using SQLite and JDBC.

---

## Technical Capabilities Tested & Validated

* Embedded database file and in-memory execution.
* Transactional schema creation and mock order queries.
* Microsecond query latency evaluation.

---

## How to Run the Tests

```bash
mvn test -pl sqlite3
```
